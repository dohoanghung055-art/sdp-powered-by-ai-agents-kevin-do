# Software Development Processes Powered by AI Agents

A hands-on course where you build AI agents that automate real software development workflows — from Git automation to architecture, requirements, CI/CD, and test-driven development.

## 📖 Description

This course walks through building a suite of AI-powered agents, each targeting a core software development process. By the end, you will have a fully integrated multi-agent system that covers the entire SDLC — using tools like Kiro, GitHub Actions, AWS SAM, and modern AI frameworks.

- **AI Agent Framework**: Kiro CLI

- **CI/CD**: GitHub Actions + AWS SAM
- **Code Quality**: pre-commit, black, ruff, bandit
- **Testing**: TDD/BDD multi-agent pipeline
